# Online Retail Data Analysis | Excel

Portfolio project analyzing online retail transactional data with Microsoft Excel.

The workbook explores sales performance, customer behavior, product performance, geographic trends, and key business metrics — combining raw data, analysis, statistics, and a concise business report.

## 📥 Download the Workbook

The Excel file is large (~44 MB). Download it from the link below once available, or clone the repository.

> **File:** `Online_Retail_Portfolio_Analysis.xlsx`  
> Open with **Microsoft Excel**

## Workbook Structure

| Sheet | Description |
|-------|-------------|
| **Year 2009-2010** | Original transactional data (first period) |
| **Year 2010-2011** | Original transactional data (second period) |
| **Analysis** | Main KPIs, sales, customer, product & geographic analysis + visualizations |
| **Statistics** | Descriptive statistics and distribution analysis |
| **Report** | Concise summary of key findings and business observations |
