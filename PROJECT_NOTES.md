## Important Upload Note
The Excel workbook is larger than GitHub's normal browser upload limit (~25 MB).

Upload the project using Git from the command line rather than dragging the `.xlsx` file into the GitHub website.

If GitHub warns about the large file, Git LFS can also be used for the `.xlsx`.
